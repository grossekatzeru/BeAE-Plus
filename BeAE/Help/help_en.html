BeAE-Plus

Help
A multitrack audio editor for Haiku. Version 3.1. Based on BeAE by Frans van Nispen. BeAE-Plus: Stas Korobov (grossekatze1@gmail.com), developed together with Claude (Anthropic).

1. Quick start

  1. Drag a sound file into the program window (or use File → Open...). The sound will land on a track as a clip.
  2. Add more files to other tracks. The volume and balance of each track are adjusted in its panel on the left.
  3. Press Space to play.
  4. Save your work: Save project (a .bemix project with all tracks) or Mixdown as... (a finished sound file).
Menu item names in this help are given as they appear in the interface. The interface language is chosen in File → Preferences... (General page).

2. The program window

  • Menu at the top: File, Edit, Transform, Analyze, Help.
  • Toolbar: new, open, save, undo and redo, cut/copy/paste, tool buttons (select, draw, play, the Jogg wheel, move track in time).
  • Track list on the left (track panels) and track strips on the right, showing the sound of the clips. The time ruler is above them.
  • Master: the common bus at the bottom of the track list, with volume, mute (M), an effects chain (FX) and L/R level meters.
  • Transport panel at the bottom: the Stop, Play, Pause, Rewind, Forward and Record buttons, zoom, time counters (current position, selection start, end and length), the tempo panel.

3. Tracks and the track panel

A project can hold up to 64 tracks. The + and − buttons above the list add and remove tracks. The track you click in becomes the active one.

4. Clips

The sound on a track is made of clips. A clip can be moved, copied, cut, locked and combined into groups.

  • Moving: drag the clip with the mouse to the desired place, including onto another track. With Sticky on, the clip snaps to the grid.
  • Selecting several clips: click the clips while holding Ctrl. Double-clicking a clip selects all clips on the track (if enabled in the preferences: "Double click selects all clips on the track"). Selected clips are tinted with one colour.
  • Split (Alt+X): cut the clip at the cursor.
  • Copy (Alt+C) and Paste (Alt+V): a copy of the clip is pasted at the cursor position. Paste clip several times... (Alt+Shift+V) pastes the clip a given number of times in a row (handy for loops).
  • Delete clip: delete the selected clip.
  • Lock in time: the clip cannot be accidentally shifted in time.
  • Group: combines two or more selected clips into a group. A group is painted in its own pastel colour and is moved and selected as a whole. Running the command again ungroups it.
  • Save clip as file...: write the clip to a sound file.
  • Paste & mix...: mix the clipboard contents into the clip under the cursor.

The clip context menu (right mouse button) contains the same commands, plus Select all, Unselect all, "Zero cross" (snapping the selection boundaries to the zero level) and the zoom commands.

5. Opening, recording and dragging files

  • File → Open... (Alt+O): opens a sound file into the active track. All formats understood by the Haiku Media Kit are read (WAV, AIFF, MP3, Ogg, FLAC and others, depending on the installed decoders). The recent files submenu shows only files that were opened in BeAE.
  • Dragging a file from Tracker into the window: the sound lands as a clip on the track under the mouse pointer, at the place where you dropped the file. Several files at once take up free tracks. If you drag a .bemix file, the project opens.
  • Recording: turn on R on the desired track and press the red Record button. Recording comes from the Haiku system audio input. If no track has R on, the program tells you so with a message. To stop, use the Stop button or press Record again.

Files cannot be opened during recording.

The audio buffer size and the recording latency can be tuned in Preferences → Audio. Recommended buffer: 2048 frames.

The Fine tune button measures the recording latency by itself: connect the sound card output to its input with a cable (or put a microphone next to the speakers) and press "Start". The program plays short clicks several times, records them and calculates the latency from the shift (corrected for the media server timestamps); the value found is put into the "Recording latency" field, and a detailed report is shown in the result window. Every new recording is also aligned by timestamps, so the media server's start jitter does not shift the take.

7. Selection and zoom

Selection

With the select tool (the first tool button) drag the mouse over a clip: the selected part is highlighted. The boundaries can be adjusted by dragging them, or by holding Shift and clicking at the desired place. The selection works within the active track; the channel is chosen with the Edit left/right/both channel commands.

  • Select all Alt+A, Unselect all Alt+U.
  • Clear Alt+B: replace the selection with silence.
  • Trim: keep only the selection.
  • Change frequency... and Resample...: change the sample rate (with or without recalculating the sound).

Zoom

"Zoom to left/right pointer" narrows the window fourfold and places the left (right) selection line at a distance of 20% of the width from the left (right) edge. The command can be repeated for ever greater magnification.

8. Tempo, grid and metronome

The tempo panel is in the lower right part of the window. It sets the project tempo (BPM), the time signature, the grid step (for example 1/4, 1/8, 1/16) and the metronome (on/off and volume).

  • The grid is displayed on tracks that have Grid on. Lines on the beats are lighter, the start of a bar is shown with a wider line. At small zoom levels dense lines are thinned out.
  • Sticky (sticky grid): when moved, clips snap to grid lines with the step selected on the tempo panel.
  • Metronome: a click on every beat of the bar, during playback and recording. The time signature and volume are saved in the project.
  • Tempo analyzer (Analyze → Tempo analyzer): detects the tempo of the sound and lets you accept it as the project tempo.

9. Track and master effects

The FX button on the track panel (and on Master) opens the Effects window: a chain of effects that are applied during playback and mixdown. The original sound of the clips is not changed.

  • Add...: add an effect. Built-in effects, LADSPA plug-ins, and also VST2 (if found in the system).
  • Remove, Up, Down: remove an effect, move it up or down in the chain.
  • Enabled: temporarily disable an effect.
  • Defaults: restore the effect's default settings.
  • Parameter values are saved with the project.

Sidechain ducking (BeFX group)

The built-in "Sidechain ducking" plug-in lowers the volume of a track while another track (the key) is playing, for example the bass under the kick drum. Its window has:

  • Key track: the key track (by name).
  • Key range: whole sound or low only.
  • Release curve: the shape of the recovery, exponential or linear.
  • Update key: recalculate the key after the key track has been edited. The indicator shows the state of the key and the amount of compression (Reduction).

10. Volume and pan automation

The volume and pan of a track can change over time: draw curves right under the track. The curves work during playback and mixdown, the original sound of the clips is not changed.

The automation strip

  • Under each track there is a thin strip. Click the triangle (or the strip) and it expands; click again to collapse it.
  • The red line is volume, the blue one is pan (the middle of the strip is the centre). For the sound, the curve sets an offset to the track slider: volume in dB (0 dB - as on the slider, the bottom - silence), pan - a shift from the slider position.
  • Clicking an empty spot adds a point, dragging moves it, right-click or double-click on a point deletes it. If both curves are visible, the point belongs to the nearest one.
  • While the strip is expanded, the Volume and Pan checkboxes appear on the track panel opposite it: which curves to show. A hidden curve keeps affecting the sound. The C button to the right of a checkbox clears the curve (grey if there is no curve).
  • The curves and the strip state are saved in the project (.bemix).

Master

Under the Master row there is the same strip: it draws the curve of the overall volume. It is also taken into account during playback and mixdown.

Recording movements

Curves do not have to be drawn, they can be recorded live with a gamepad (section Gamepad control): turn on automation recording mode, start playback and move the stick - the volume and pan of the active track are written into the curves instead of moving the sliders.

11. Gamepad control

The volume and pan of the active track can be controlled with a USB joystick or gamepad. The device and the bindings are set up in Preferences → Controllers.

  • Device: choose from the list (the "Rescan" button searches again). Below, the axes, hats and buttons are shown live: this is how you check that the controller is visible.
  • Bindings: each action has a button with its current source. Press it, then press a button or deflect an axis on the controller - the binding is remembered. The "x" button clears a binding, "Defaults" restores the original ones. One source can be assigned to only one action.
  • A source is a button or an axis direction. A digital d-pad, which many gamepads report as axes, works like a stick with smooth travel: the further the deflection, the faster the value changes.
  • Sliders: Volume speed (dB/s), Pan speed and the axis Dead zone.

14. Analysis: spectrum, scope, tempo, tuner

  • Spectrum analyzer: the spectrum of the sound.
  • Sample scope: an oscilloscope of the selected part.
  • Tempo analyzer: tempo detection.
  • Tuner: a tuner for guitar and bass. It listens to the audio input without recording. Choose a tuning (all notes, guitar 6 or 7 strings, bass 4 or 5 strings), the note naming (C D E or Do Re Mi) and the A4 frequency. Press Start and play a string: the green scale shows the deviation. The tuner is unavailable during recording.

15. Insert from MIDI

File → Insert from MIDI... (Alt+I) turns a MIDI file into sound using a SoundFont (SF2).

  1. In the panel that opens, choose a MIDI file. The Play button at the bottom left plays it with the Haiku system MIDI synthesizer (the bank from the system Midi settings sounds, not the BeAE SoundFont): this is only to get an idea of the file.
  2. The parameters window shows: the file name, the number of tracks with notes, the SoundFont and the tempo.
  3. In the MIDI Effects frame, turn on the effects you need: Pan, Reverb, Chorus. Reverb and Chorus need plug-ins from this package.
  4. If the MIDI tempo differs from the project tempo, choose: accept the MIDI tempo for the project, fit the MIDI to the project tempo, or keep both.
  5. Press Insert: the MIDI is synthesized and placed on free tracks.

The default sound bank is chosen in Preferences → Audio (the MIDI section). *.sf2 SoundFont files are searched for in the Haiku synthesizer folders.

16. Project (.bemix)

A project stores tracks, clips, volume, balance, automation curves, effects, groups, tempo and metronome. It is not a sound file but a folder with links to the sound and a description of the project.

  • New project (Alt+Shift+N), Open project... (Alt+Shift+O), Save project, Save project as....
  • The open panel shows folders and *.bemix files.
  • A .bemix file can be dragged into the BeAE window and it will open.

17. Saving and mixdown

Saving the sound of the active track

Save (Alt+S), Save as... (Alt+Shift+S) and Save selection... (Alt+Ctrl+S) open the save panel. The extension is added automatically according to the chosen format.

Panel fieldPurpose
FormatUncompressed (PCM) writes WAV (16, 24 or 32 bits, as in the original sound); Compressed uses an external encoder.
CodecAvailable when the format is "Compressed". Shows the encoders found in the system: MP3 (lame), Ogg Vorbis (oggenc), FLAC (flac), Opus (opusenc).
Options...Settings of the selected encoder (below).

Compression settings ("Options..." button)

CodecSettings
MP3 (lame)VBR / CBR / ABR mode; V quality (0 is best, default 2); bitrate 32-320 kbps for CBR and ABR; stereo: joint, stereo, mono.
Ogg Vorbis (oggenc)"By quality" mode (0-10, default 5) or "by bitrate" (32-320 kbps).
FLAC (flac)Compression level 0-8 (default 5). Lossless; the higher the level, the smaller the file and the longer the encoding.
Opus (opusenc)VBR or CBR mode; bitrate 6-510 kbps (default 128).

For all codecs you can set tags: artist, album, year, comment. The title is taken from the file name. The settings are remembered.

The encoders lame, oggenc, flac and opusenc are external programs, they must be installed in the system (for example, pkgman install lame flac vorbis_tools opus_tools). If none is present, the "Codec" field shows a hint.

Mixdown

  • Mixdown (Alt+M): mixes all the project tracks (taking into account volume, balance, automation curves, effects, mute/solo) into a sound file. The .wav extension is added automatically.
  • Mixdown as...: the same with a choice of format. Compressed formats go through external encoders, as above.

If all tracks are empty or muted, the mixdown reports that there is nothing to mix.

20. FAQ

The compressed format is unavailable, the codec list is empty.
Install the needed encoder (lame, oggenc, flac, opusenc). Check in Terminal: which lame.

LADSPA plug-ins are not visible in the menu.
Run make install in the plugins folder and press "Rescan plug-ins" in the LADSPA submenu. Plug-ins are searched for in the plugins folder next to the program and in the standard LADSPA folders.

Recording does not start.
Turn on R on the track you want to record into.

The file does not open.
The message "This file is not supported" means that the system has no decoder for this format. Check whether the file opens in MediaPlayer.

Clicks during playback.
Increase the audio buffer in Preferences → Audio.
