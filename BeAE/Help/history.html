Version 3.1 (BeAE-Plus)November 2026

Automation and hardware control: volume and pan curves for every track and the master, and control of the mixer from a USB gamepad, including live recording of the moves into the curves. Recording latency measurement was reworked.

Fixed:

  • Recording latency (Preferences → Audio → Fine tune) is measured stably (about 0.3 ms spread) and recordings made at different times lie on top of each other within about 1.5 ms; the start jitter of the media server no longer shifts a take
  • Recording compensation was silently inactive in the RAM build of the player, now both player variants work

Added:

  • Automation strips: under every track a thin strip that expands on a click; red line = volume, blue line = pan; click adds a point, drag moves it, right button or double click deletes it; the curves add to the track sliders and are heard in playback and in mixdown (WAV and compressed formats)
  • Master automation strip below the Master row (volume curve), with a separator line
  • Check boxes Volume / Pan in the free space of the track panel (shown only while the strip is expanded) select which curves are drawn; a hidden curve still works; the small C button next to each clears the curve
  • Curves and the state of the strips are saved in the project (.bemix)
  • Gamepad / joystick control (Preferences → Controllers): device selection, live view of axes, hats and buttons, every action can be rebound with Bind (press a button or move an axis on the controller), digital D-pads and analogue sticks are both supported (the speed follows the deflection), adjustable volume speed, pan speed and dead zone; the default bindings are set by the program
  • Gamepad actions: volume up/down and pan left/right of the active track, pan to center, volume 0 dB, previous/next track, hold for master volume, play/stop, automation write on/off
  • Automation write: with the mode on, moving the stick during playback records the volume and pan moves of the active track (or the master) into the curves; the mode is shown in the window title
  • The diagnostic report of Fine tune (per-trial timing and the applied correction) is shown in the result window
  • Help rewritten for the new features and translated into English (help_en.html is opened when the interface language is not Russian)


Version 3.0 (BeAE-Plus)November 2026

BeAE becomes a multitrack editor. The single sample of the old versions is now a project with tracks and clips, and a mixer, effect chains, a MIDI importer, a tuner and external encoders were added around it.

Fixed:

  • Opening an audio file could hang forever when the decoder returned no frames; the decoder is now asked for raw float audio and the read loop is guarded
  • Saving: files that could not be opened afterwards (8 bit, clipped peaks, mime type set before the file was closed, empty leftovers after errors)
  • The open menu showed the recent files of the whole system, now only the files opened in BeAE
  • The BeAE input stayed in the system mixer after quitting
  • MIDI: pitch bend range (RPN 0) was ignored, bends sounded out of tune
  • The tuner readout jumped too fast to read, now smoothed
  • Lanes scroll bar now covers the full height of the work area
  • Zoom to left/right pointer: the pointer stays at 20% from the edge

Added:

  • Multitrack: up to 64 tracks with Solo, Mute, Record, volume, pan, Grid, Xfade and Sticky; Master strip with In and Out level meters and effects
  • Clips on a common timeline: split, copy, paste several times, move between tracks, delete, lock in time, groups, selecting several clips, save clip as a file
  • Files can be dropped into the window, a new clip is placed under the mouse
  • Recording into the armed track while the other tracks play, with live waveform and a follow-the-record view; automatic measurement of the recording latency (Preferences → Audio → Fine tune), with a detailed diagnostic report; each recording is aligned using the media buffer timestamps, so the start jitter of the media server no longer shifts the take
  • Projects (.bemix): save, open, save as, new; mixdown of all tracks, Mixdown as...
  • Per-track and master effect chains: built-in effects, LADSPA and VST2 plug-ins, parameters with exact value fields, saved in the project
  • Plug-ins: spring reverb, adaptive noise reduction, graphic and parametric equalizers, multiband compressor, reverb, plate reverb (EMT 140), 80s vocal chain, flanger, chorus, optical compressor, distressor, gate/expander, Tube Screamer overdrive, DS-1 distortion, auto-tune, sidechain ducking (BeFX)
  • Tempo and grid: BPM, time signature, metronome, beat and bar lines, tempo analyzer
  • Insert from MIDI: own SoundFont (SF2) synthesizer, MIDI effects (pan, reverb, chorus), tempo import, preview in the file panel
  • Tuner (Analyze → Tuner) for guitar and bass
  • Save as: uncompressed (PCM) or compressed through the external encoders lame, oggenc, flac and opusenc, with their options and tags; the file extension is added automatically
  • Complete help in the new documentation (Russian) and a cleaned up version history


Version 1.2
  • October 2009 - Updated build system to use CMake, updated graphics, fixed some build warnings, no new functional changes.
  • August 2009 - First release under new name, now running on Haiku.
  • 2006 - Removed references to the original name, renamed to BeAE and posted on Berlios.de
  • 2003 - Released as open source

From BeGroovy: "In what ultimately amounts to a mixed fate, Sample Studio by Xentronix has been open sourced, after community members paid a $250 source release fee. This was done because Xentronix no longer has time to continue work on the product, and didn't want it to just become abandonware.
So, the downside is that Sample Studio, a potentially great audio editing app for BeOS, has seen its core developers stop development. The upside is that it is now free software, so it has potential to grow quickly if new developers pick it up."
