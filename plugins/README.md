# Плагины BeAE-Plus

Самостоятельные плагины LADSPA. Приложение от них не зависит; их может использовать любой хост LADSPA.

(Шумодав встроен в BeAE, меню Transform → «Шумодав»: он работает над выделением, а не в цепочке дорожки.)

| Файл | Название | Что делает |
|---|---|---|
| `spring_reverb/` → `spring_reverb.so` | Ламповое эхо (пружинный реверб) | имитация пружинного ревербератора, 3–5 пружин |
| `sadp/` → `sadp.so` | САДП (адаптивное шумоподавление) | односторонний шумодав для плёнок: приглушает полосы, где нет сигнала; без задержки, работает в потоке |
| `graphic_eq/` → `graphic_eq.so` | Графический эквалайзер, 6 / 12 / 18 полос | в библиотеке три плагина; ползунки ±12 дБ, пиковые фильтры с перекрытием полос |
| `parametric_eq/` → `parametric_eq.so` | Параметрический эквалайзер, 3 / 5 полос | НЧ-полка, колокола (частота, усиление, Q), ВЧ-полка; ±15 дБ |
| `multiband/` → `multiband.so` | Многополосный компрессор | 4 полосы, у каждой порог, степень, атака, спад, усиление; 3 регулируемые границы, мягкое колено, соло полосы; без задержки |
| `autotune/` → `autotune.so` | Автотюн (вокал) | подтягивает фальшивые ноты голоса к строю: определение высоты YIN, сдвиг PSOLA; задержка 50 мс (порт `latency`) |

## Устройство папки

    plugins/
      Makefile            общий: собирает все плагины (по подпапкам с Makefile)
      common.mk           общие правила сборки одного плагина
      common/ladspa_abi.h интерфейс LADSPA
      spring_reverb/      один плагин: исходники и свой Makefile

Новый плагин: создать подпапку, положить исходники и `Makefile` из четырёх строк (NAME, SRCS, GROUP, include ../common.mk).
Общий Makefile подхватит его сам. Функция `ladspa_descriptor` должна быть экспортирована (`extern "C"`).

## Сборка и установка (Haiku)

    cd plugins
    make                  # все плагины
    make install          # ~/config/non-packaged/lib/ladspa/<группа>/
    make install DEST=/путь/BeAE/plugins    # папка plugins рядом с BeAE (подпапка группы станет подменю)

    cd spring_reverb && make && make install    # только один плагин

BeAE ищет плагины в `plugins` рядом с программой (вместе с подпапками, глубина до 3, подпапка = подменю),
а также в стандартных папках LADSPA (`~/config/lib/ladspa`, `~/config/non-packaged/lib/ladspa`,
`/boot/system/lib/ladspa`, `/boot/system/non-packaged/lib/ladspa`, переменная `LADSPA_PATH`).

## Особенности

- Оба плагина стерео (2 входа, 2 выхода).
- Эквалайзеры: полоса с нулевым усилением пропускается, при всех нулях звук проходит без изменений. Частоты полос графического: 6 полос — 63, 200, 630 Гц, 2, 6,3, 16 кГц; 12 — от 40 Гц до 16 кГц; 18 — полуоктавные, 45 Гц…16 кГц. В параметрическом первая полоса — НЧ-полка, последняя — ВЧ-полка, остальные колокола.
- Автотюн: один голос (не аккорды). Строй: 0 хроматика, 1 мажор, 2 натуральный минор, 3 гармонический минор, 4 и 5 пентатоника; тональность 0 = до … 11 = си. «Скорость коррекции» 0 мс даёт роботический эффект; «Степень» меньше 100 % оставляет часть живости. Задержка 50 мс компенсируется в BeAE; другой хост без компенсации сдвинет голос.
- Плагины стерео (2 входа, 2 выхода), без задержки.
- САДП: пять полос (НЧ, средние всегда открыты, три полосы ВЧ). Порог полосы = максимум из «Порога шума» и уровня основного сигнала минус «Контраст». «Начало ВЧ» от 1000 до 16000 Гц (по умолчанию 4000): чем ниже, тем уже всегда открытая средняя полоса. «Подавление» задаёт глубину, «Атака» скорость открытия полосы, «Спад» скорость закрытия. Реализован по описанию (точная схема 1975–1979 гг. не использовалась), параметры подбираются на слух.
- Многополосный компрессор: границы между полосами по умолчанию 173 Гц, 1,1 кГц, 5,7 кГц. Для каждой полосы: порог (−15 дБ), степень (около 2,1:1), атака (10 мс), спад (140 мс), усиление (0 дБ). Детектор общий для обоих каналов, уровень измеряется среднеквадратично (5 мс). «Слушать полосу» (1–4) для настройки границ на слух. При степени 1 и нулевом усилении звук проходит без изменения амплитуды (только фазовый сдвиг от разделения на полосы). Де-эссер: сильнее сжать верхнюю полосу и поставить границу 3 около 5–6 кГц.
- Названия портов на русском (UTF-8).
- Значения по умолчанию заданы подсказками LADSPA (HINT_DEFAULT_*), поэтому одинаковы в любом хосте.
