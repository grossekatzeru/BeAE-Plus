# Плагины BeAE-Plus

Самостоятельные плагины LADSPA. Приложение от них не зависит; их может использовать любой хост LADSPA.

(Шумодав встроен в BeAE, меню Transform → «Шумодав»: он работает над выделением, а не в цепочке дорожки.)

| Файл | Название | Что делает |
|---|---|---|
| `spring_reverb/` → `spring_reverb.so` | Ламповое эхо (пружинный реверб) | имитация пружинного ревербератора, 3–5 пружин |
| `sadp/` → `sadp.so` | САДП (адаптивное шумоподавление) | односторонний шумодав для плёнок: приглушает полосы, где нет сигнала; без задержки, работает в потоке |
| `graphic_eq/` → `graphic_eq.so` | Графический эквалайзер, 6 / 12 / 18 полос | в библиотеке три плагина; ползунки ±12 дБ, пиковые фильтры с перекрытием полос |
| `parametric_eq/` → `parametric_eq.so` | Параметрический эквалайзер, 3 / 5 полос | НЧ-полка, колокола (частота, усиление, Q), ВЧ-полка; ±15 дБ |
| `multiband/` → `multiband.so` | Многополосный компрессор | 4 полосы, у каждой порог, степень, атака, спад, усиление; 3 регулируемые границы, мягкое колено, соло полосы; без задержки |
| `reverb/` → `reverb.so` | Реверберация | алгоритмический реверб (8 гребенчатых + 4 всепропускающих фильтра на канал): размер, затухание высоких, смесь (посыл), предзадержка, ширина; при импорте MIDI получает значение контроллера CC91 |
| `plate_reverb/` → `plate_reverb.so` | Пластинчатый реверб (EMT 140) | модель пластины EMT 140 (топология Даттарро): плотный яркий хвост без отдельных эхо, время затухания 0,5–8 с, срез низких (слабый бас пластины), затухание высоких, плотность, лёгкая модуляция, ширина стерео, предзадержка, смесь (посыл) |
| `vocal_chain/` → `vocal_chain.so` | Вокальная цепочка 80-х (слэп + пластина) | готовая связка для поп-вокала: короткая задержка (слэп, 10–80 мс, повторы, уровень) + пластинчатый реверб (затухание, предзадержка, завал высоких в хвосте, уровень); по умолчанию 30 мс / 5 % / 12 % и 1,8 с / 32 мс / 4,5 кГц / 25 % |
| `flanger/` → `flanger.so` | Фленджер | короткая плавающая задержка (0,2–10 мс «ручная» + глубина 0–1, скорость 0,05–5 Гц), обратная связь ±95 % (минус даёт «металлический» звук), стерео-разнесение фаз LFO 0–180°, смесь (посыл; 100 % даёт глубокие провалы гребёнки) |
| `la2a/` → `la2a.so` | Оптический компрессор (LA-2A) | в духе Teletronix LA-2A: «Сжатие» (порог до −40 дБ), усиление, режимы Compress (3:1) / Limit (10:1), очень мягкое колено, атака ~10 мс, возврат зависит от программы (быстрый после коротких пиков, медленный после долгого сжатия), ламповая сатурация, параллельная смесь; каналы связаны |
| `distressor/` → `distressor.so` | Компрессор «Дистрессор» | в духе Empirical Labs Distressor: вход/выход, порог, степень 1–20:1, атака 0,05–100 мс, возврат 20 мс–3 с, режимы «Обычный» / «Мягкий (оптика)» / «Nuke» (почти лимитер), фильтр детектора 20–400 Гц, гармоники чётные (лампа) или нечётные (транзистор), параллельная смесь |
| `chorus/` → `chorus.so` | Хорус | три голоса с плавающей задержкой, стерео: скорость, глубина, смесь (посыл), обратная связь; при импорте MIDI получает значение контроллера CC93 |
| `autotune/` → `autotune.so` | Автотюн (вокал) | подтягивает фальшивые ноты голоса к строю: определение высоты YIN, сдвиг PSOLA; задержка 50 мс (порт `latency`) |

## Устройство папки

    plugins/
      Makefile            общий: собирает все плагины (по подпапкам с Makefile)
      common.mk           общие правила сборки одного плагина
      common/ladspa_abi.h интерфейс LADSPA
      spring_reverb/      один плагин: исходники и свой Makefile

Новый плагин: создать подпапку, положить исходники и `Makefile` из четырёх строк (NAME, SRCS, GROUP, include ../common.mk).
Общий Makefile подхватит его сам. Функция `ladspa_descriptor` должна быть экспортирована (`extern "C"`).

## Сборка и установка (Haiku)

    cd plugins
    make                  # все плагины
    make install          # ~/config/non-packaged/lib/ladspa/<группа>/
    make install DEST=/путь/BeAE/plugins    # папка plugins рядом с BeAE (подпапка группы станет подменю)

    cd spring_reverb && make && make install    # только один плагин

BeAE ищет плагины в `plugins` рядом с программой (вместе с подпапками, глубина до 3, подпапка = подменю),
а также в стандартных папках LADSPA (`~/config/lib/ladspa`, `~/config/non-packaged/lib/ladspa`,
`/boot/system/lib/ladspa`, `/boot/system/non-packaged/lib/ladspa`, переменная `LADSPA_PATH`).

## Особенности

- Оба плагина стерео (2 входа, 2 выхода).
- Эквалайзеры: полоса с нулевым усилением пропускается, при всех нулях звук проходит без изменений. Частоты полос графического: 6 полос — 63, 200, 630 Гц, 2, 6,3, 16 кГц; 12 — от 40 Гц до 16 кГц; 18 — полуоктавные, 45 Гц…16 кГц. В параметрическом первая полоса — НЧ-полка, последняя — ВЧ-полка, остальные колокола.
- Автотюн: один голос (не аккорды). Строй: 0 хроматика, 1 мажор, 2 натуральный минор, 3 гармонический минор, 4 и 5 пентатоника; тональность 0 = до … 11 = си. «Скорость коррекции» 0 мс даёт роботический эффект; «Степень» меньше 100 % оставляет часть живости. Задержка 50 мс компенсируется в BeAE; другой хост без компенсации сдвинет голос.
- Плагины стерео (2 входа, 2 выхода), без задержки.
- САДП: пять полос (НЧ, средние всегда открыты, три полосы ВЧ). Порог полосы = максимум из «Порога шума» и уровня основного сигнала минус «Контраст». «Начало ВЧ» от 1000 до 16000 Гц (по умолчанию 4000): чем ниже, тем уже всегда открытая средняя полоса. «Подавление» задаёт глубину, «Атака» скорость открытия полосы, «Спад» скорость закрытия. Реализован по описанию (точная схема 1975–1979 гг. не использовалась), параметры подбираются на слух.
- Многополосный компрессор: границы между полосами по умолчанию 173 Гц, 1,1 кГц, 5,7 кГц. Для каждой полосы: порог (−15 дБ), степень (около 2,1:1), атака (10 мс), спад (140 мс), усиление (0 дБ). Детектор общий для обоих каналов, уровень измеряется среднеквадратично (5 мс). «Слушать полосу» (1–4) для настройки границ на слух. При степени 1 и нулевом усилении звук проходит без изменения амплитуды (только фазовый сдвиг от разделения на полосы). Де-эссер: сильнее сжать верхнюю полосу и поставить границу 3 около 5–6 кГц.
- Названия портов на русском (UTF-8).
- Значения по умолчанию заданы подсказками LADSPA (HINT_DEFAULT_*), поэтому одинаковы в любом хосте.

## Пластинчатый реверб

По описанию EMT 140 (1957): стальная пластина, плотный и продолжительный хвост, яркий звук, слабый бас, время затухания регулируется демпфером, два датчика на выходе дают стерео. Здесь это алгоритмическая модель, а не точная копия: вход (моно) → срез низких → предзадержка → четыре диффузора → «бак» из двух перекрёстных ветвей с модуляцией и демпфированием высоких → выход со снятием с нескольких точек. «Время затухания» (RT60 на средних частотах) выставляется точно и не зависит от частоты дискретизации (проверено на 22,05 / 44,1 / 48 / 96 кГц). Для вокала и ударных: затухание 1,5–3 с, срез низких 100–200 Гц, смесь 15–30 %, предзадержка 10–40 мс. Параметры подбираются на слух.

## Вокальная цепочка 80-х (слэп + пластина)

Один плагин вместо двух: слэп-задержка 10–80 мс (почти «дабл-трек», повторы 0–30 %, уровень 0–50 %) и пластинчатый реверб с предзадержкой 0–100 мс. Реверб получает сухой сигнал вместе со слэпом, хвост проходит завал высоких (2–16 кГц, 12 дБ/окт), затем добавляется с уровнем «Реверб, %». Значения по умолчанию — типовая рекомендация для поп-вокала: слэп 30 мс / повторы 5 % / уровень 12 %, реверб 1,8 с / предзадержка 32 мс / завал 4,5 кГц / уровень 25 %. Для баллады увеличьте затухание до 2,2 с и уровень реверба до 30 %. Ядро пластины общее с плагином «Пластинчатый реверб» (`common/plate_core.h`).

## Фленджер, LA-2A, Дистрессор

Все три — обычные независимые плагины (группы Modulation и Dynamics). **Фленджер**: «Смесь» работает как посыл, 100 % даёт полные провалы гребёнки; для классического «реактивного» звука поставьте глубину 0,7–1, обратную связь 40–70 %, скорость 0,1–0,3 Гц. **LA-2A**: порядок работы как у прибора — «Сжатие» до 3–6 дБ на пиках вокала, «Усиление» подтягивает громкость; Limit жёстче, «Лампа» 20–30 % добавляет тёплые чётные гармоники. **Дистрессор**: для вокала степень 3–6:1, атака 1–5 мс, возврат 100–300 мс; «Nuke» — жёсткое ограничение; режим «Мягкий» похож на оптику; гармоники «чётные» — тёплые, «нечётные» — резче; для ударных можно подмешать сжатый сигнал через «Параллельно». Это модели «по описанию приборов», не точные копии; параметры подбираются на слух.

## Реверберация и хорус: связь с MIDI

Это обычные плагины для любой дорожки (в названии нет слова MIDI). При «Файл → Вставить из MIDI» с галочкой «Добавить эффекты MIDI» BeAE подключает их к дорожкам с параметрами из файла: CC91 → «Реверберация», «Смесь, %» (значение 127 = 50 %), CC93 → «Хорус», «Смесь, %» (127 = 100 %), CC10 (панорама) → баланс дорожки. Остальные параметры остаются по умолчанию. Если плагины не установлены (`make install`), импорт сообщит об этом. Соответствие записано в `Core-src/MidiImport.cpp` (kReverbRole, kChorusRole).
